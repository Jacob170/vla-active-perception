Why this reading is wrong, precisely. §8.3 line 2 reads “Sample N action chunks A⁽¹⁾…A⁽ᴺ⁾ by running the flow ODE from N independent noise seeds.” One flow-ODE pass produces one A ∈ ℝH×7 — H future timesteps of a chunk, not an episode played to completion. Nothing in the algorithm executes those actions in the environment before clustering.

Where the confusion enters

Both readings involve “N trajectories.” The difference is whether a trajectory is H = 10 predicted future timesteps from a single forward pass, or ~125 executed environment steps. The MD file uses the first meaning throughout; the word “trajectory” in casual speech suggests the second.

Scenario A cost passes = N × steps_per_episode × K  =  10 × 125 × 125  =  156,250
Scenario B cost (see companion document) passes = (1 + N) × K  =  (1 + 10) × 125  =  1,375
