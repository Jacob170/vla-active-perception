Steps, in order

  1. Observeot = agentview image + wrist image + proprioceptive state. Both cameras always on — confirmed in libero_policy.py.
  2. Encode the backbone once1 forward pass. §6: “the expensive part runs once, the cheap part runs N times.” This asymmetry is what makes the method affordable.
  3. Sample N chunksN independent noise seeds through the flow ODE, ~10 Euler steps each. Output: N tensors of shape (H, 7) = (10, 7). Batch these.
  4. Pose-integrate each chunkAccumulate the 10 deltas into one terminal pose. Position sums; orientation composes on SO(3); gripper takes the last value.
  5. Cluster greedilyCompare each chunk to one representative per existing cluster. Join if d ≤ ε, else open a new cluster. Order-dependent — fix and report the seed.
  6. Count and measurep̂c = nc/N, then Shannon entropy over the cluster distribution. Apply Miller–Madow.
  7. Aggregate, threshold, actFeed SEt into Layer 2 (§11), threshold it, execute the chosen chunk prefix, advance to t+1.

Where each calculation happens

Step 04 · pose integration — position pterm = p0 + Σh=1..H Δph A plain running sum. p0 is the current end-effector position, known from proprioception — no kinematics needed to obtain it.
Step 04 · pose integration — orientation Rterm = ΔRH ∘ … ∘ ΔR2 ∘ ΔR1 ∘ R0 Rotations do not add — they compose. SO(3) is curved, so this is matrix or quaternion multiplication applied in sequence, not a sum.
Step 05 · behavioural distance — §8.2 d(A,B) = ‖pA − pB‖₂  +  λR · dgeo(RA, RB)  +  λg · |gA − gB| metres + λR·radians + λg·binary. The units are incommensurable until λR and λg are calibrated — §8.2 requires λg large enough that gripper disagreement always forces separate clusters.
Step 05 · cluster assignment rule join cluster c  ⟺  d(A(i), rep(c)) ≤ ε One comparison per existing cluster, not all pairs: O(N·|C|), mirroring Farquhar's greedy sequential clustering exactly.
Step 06 · discrete estimator — §3.3 step 3b p̂(c | x) = nc / N Pure counting. No likelihoods anywhere — which is exactly why this is the only estimator available for flow matching (§4, §7).
Step 06 · semantic entropy — §3.3 step 4 SEt = − Σc ∈ 𝒞 p̂c · ln p̂c Standard Shannon entropy, applied to the distribution over outcome clusters instead of raw outputs. That substitution is the whole method. Ceiling: SE ≤ ln N.
Step 06 · bias correction — §9 ĤMM = Ĥplug-in + (Ĉ − 1) / (2N) The plug-in estimator is biased downward by roughly −(Ĉ−1)/(2N). Costs nothing to correct. Ĉ renamed from the MD file's K̂ — see the collision note below.
Step 07 · Layer-2 aggregation — §11 St = maxw ∈ 𝒲 poolw[ z( (1 + λ · ATRt) · SEt ) ] ATR gate and max-pool survive the swap from token entropy unchanged. The β-weighted DoF sum disappears — SE is already a scalar. z-scoring becomes mandatory, since SE has a different scale and a hard ln N ceiling.

Scenario C — trigger at chunk boundaries

The chunk prefix actually executed is shorter than the chunk predicted. openpi's LIBERO example uses replan_steps = 5: predict H=10, execute 5, re-predict. If SE is computed only when a new chunk is generated rather than at every environment step, K drops by that factor.

Two different K’s — fix before writing up. §9 uses K̂ for the number of observed clusters in the Miller–Madow term. This document uses K for the control-step loop count, and the perturbation paper (arXiv 2606.20754) uses K for its sample count — the role your N plays. Three meanings, one letter.

Recommended: cluster count → Ĉ, sample count stays N, loop count stays K. Applied throughout this document already.

One design choice this diagram does not yet make. The perturbation paper reuses the same noise tensor at every timestep, deliberately, so each perturbed variant stays temporally consistent across a rollout. This flow resamples fresh seeds at every reading. If temporal consistency of samples turns out to matter for stable clustering, that is a decision to make on purpose — currently unaddressed in the MD file.
